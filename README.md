# Tavelo Home Shopify Theme

A custom Shopify Online Store 2.0 theme for Tavelo Home, built with Liquid, JSON templates, CSS and JavaScript.

This repository is being prepared for the Shopify store `tavelohome.myshopify.com`.

## Development

- Keep the product catalogue and prices managed in Shopify Admin.
- Use Shopify theme editor settings for the brand colours, hero image, featured product and copy.
- Preview the theme as an unpublished theme before publishing.
- Do not publish until supplier details, product compatibility, shipping rates, payment gateway, returns policy and contact details have been verified.

## Connect to Shopify

In Shopify Admin, go to **Online Store → Themes → Add theme → Connect from GitHub** and select this repository and the `shopify-theme` branch after it has been created.

This is a theme repository, not a standalone hosted storefront.
